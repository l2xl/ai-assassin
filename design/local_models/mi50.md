# `mi50`

Two 32 GB AMD Instinct MI50 cards of the user's server, served by one inference engine per preset:
`mi50-llamacpp` ([mi50_llamacpp.md](mi50_llamacpp.md)) and `mi50-strata` ([mi50_strata.md](mi50_strata.md)). Each is an
independent compose project, a preset knowing nothing of the other. Each names the server and what a model server on the
cards needs, and defines no model — which models it serves, and what for, is left to the services added to it. Until one is,
`up` refuses it.

What the two compose files share, each stating it in the `x-` block a service merges:

- the cards — `/dev/kfd`, `/dev/dri` and the server's `video` and `render` groups;
- the models — the server's folder of GGUF files, `/home/alexey/models` unless `MI50_MODELS` names
  another, mounted read-only at `/models`.

What differs is the engine's image and what it asks of a service, described in the file of each preset. Both presets run on the
same cards, and nothing checks that what they serve at once fits the cards together.

## The server

Both presets name the docker host `ssh://alexey@213.158.1.168:49999`, so every docker call of the
command goes there, needing on this machine the docker client with its compose plugin and an SSH key
the server accepts. The servers of their services listen on the server's loopback and are reached here
through an SSH tunnel of their ports (`ssh -p 49999 -N -L <port>:127.0.0.1:<port> alexey@213.158.1.168`).
